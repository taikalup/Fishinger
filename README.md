# Fishinger
## Usage

### Installing the mod

1. Download the appropriate release file for your Minecraft version from the **Releases** page.
2. Make sure you have **Fabric Loader** installed for the corresponding Minecraft version.
3. Place the downloaded `.jar` file into your Minecraft `mods` folder.
4. Launch Minecraft using the Fabric Loader profile.

Make sure that the mod version, Minecraft version, and Fabric Loader version are compatible.
